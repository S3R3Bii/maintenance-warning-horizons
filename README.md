# Remaining-life prediction and a limited inspection batch

Protocol/source stage. This study will compare remaining-life errors, calibrated uncertainty and inspection capture across engine-unit holdouts and a separate operating-condition stress dataset. All source engines are simulated. No performance result is claimed yet.

The original public archive is accessed through the official NASA-linked mirror. Raw members and source paper remain local; the planned public package contains original code, source access/hashes, derived results, figures and checks. Manuscript drafts remain private.
