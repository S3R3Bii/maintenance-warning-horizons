# Simulation source and limited redistribution

A. Saxena and K. Goebel (2008), **Turbofan Engine Degradation Simulation Data Set**, NASA Prognostics Data Repository, NASA Ames Research Center, Moffett Field, California. Reference paper: A. Saxena, K. Goebel, D. Simon and N. Eklund, *Damage Propagation Modeling for Aircraft Engine Run-to-Failure Simulation*, PHM2008.

- [Official repository and mirror link](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/).
- [Official dataset description](https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data).
- [NASA-linked public archive](https://phm-datasets.s3.amazonaws.com/NASA/6.+Turbofan+Engine+Degradation+Simulation+Data+Set.zip).

The portal marks the dataset's license as unspecified. This project therefore does not redistribute the raw archive, original README or original paper and asserts no blanket source-data license. The retrieval script provides access at the official public source, verifies a fixed archive hash and stores selected members locally. Public code and derived analyses are this project's work; no NASA review or endorsement is implied.

The dataset is generated by simulation. The source describes noisy trajectories, different initial wear, multiple operating settings and truncated official test trajectories with remaining-life labels. These are not actual commercial-engine or maintenance records. The source's prose lists26 total columns but its final sensor-number example is inconsistent; the parser checks26 numeric columns and uses21 neutral sensor labels after the five identity/time/setting columns. No physical sensor name or unit beyond source-supported cycle counts is invented.
